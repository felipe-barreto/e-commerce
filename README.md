# Aplicación web responsive y accesible - E-commerce

La aplicación permite a los usuarios ver los productos de la tienda, filtrarlos por categoría, consultar la información detallada de cada uno y agregarlos al carrito. En el carrito se listan los productos seleccionados, y se puede incrementar o reducir la cantidad de unidades de cada uno; además de mostrarse el precio total de la compra.

<br>

## Para su construcción se utilizaron las siguientes herramientas y tecnologías:

- Vite para la creación y configuración inicial del proyecto.

- React para crear la interfaz de usuario a partir de componentes.

- TypeScript para detectar errores durante el desarrollo.

- Tailwind CSS para los estilos.

- React Router DOM para el enrutamiento.

- React Redux y Redux Toolkit para el manejo del estado global.

- Git para el control de versiones.

- GitHub para el alojamiento del repositorio.

<br>

## Instalación

git clone https://github.com/felipe-barreto/e-commerce

cd e-commerce

npm i

npm run dev
